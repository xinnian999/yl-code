# Niuma Code

终端内 AI 助手 CLI，输入 `niuma` 即可召唤使用。

## 安装

```bash
npm install -g niuma-code
```

## 使用

```bash
niuma
```

## 功能

- 🤖 终端内的 AI 对话助手
- 💬 支持 Markdown 渲染
- 🔧 支持 MCP (Model Context Protocol) 扩展
- 📝 内置代码差异对比与确认
- 📜 会话历史记录
- ✅ 任务列表管理

## 开发

```bash
# 安装依赖
bun install

# 开发模式
bun run dev

# 构建
bun run build

# 类型检查
bun run typecheck
```

## 要求

- Node.js >= 18.0.0
